# Build Math Skills — Recommendations

**Source:** bwu.neuro.reports.recs.build-math-skills
**Tags:** recs, math, dyscalculia

## Overview

This document provides a set of clinical recommendations for parents and teachers to support a student with [[concepts/dyscalculia]] or significant math learning difficulties. Strategies span foundational number sense, automaticity, conceptual understanding, and real-world generalization.

## Key Recommendation Areas

### Foundational Number Skills
- Use egg cartons and physical objects to develop **rote counting** and **one-to-one correspondence**.
- Practice skip counting (by 2s, 3s, 4s, 5s, 6s, etc.) to build a foundation for multiplication as repeated addition.

### Visual-Spatial Supports
- Allow use of **graph paper** to help align multi-digit numbers, compensating for poor [[concepts/visual-organizational-skills]].
- Use **visual cues** to teach operations involving sequencing or serialization.

### Math Fact Automaticity
- Use mnemonics, rhymes, finger tricks (e.g., multiplying by 9), and flash cards.
- Incorporate **digital games** with immediate feedback and reinforcement to build retrieval speed.

### Hands-On and Manipulative Learning
- Incorporate manipulatives, drawing, and hands-on activities when teaching new concepts.
- Use weighted plastic bags to teach relational concepts around **mass** (heavier/lighter).
- Attach coins to index cards with illustrations to support **money skills** and recall.

### Real-World Generalization
- Encourage application of math skills to everyday contexts: shopping, making change, cooking, travel time estimation.
- Parents should model mathematical thinking in daily life.

### Assessment Accommodations
- Allow **calculator use** on tests assessing procedural knowledge rather than computational skill.
- Provide **extended time** on math tests and quizzes.
- See also [[concepts/iep-accommodations]] for broader accommodation frameworks.

### Intervention
- Participate in an evidence-based math intervention targeting specific areas of weakness, consistent with [[concepts/math-interventions]].
- Monitor progress closely; escalate to more intensive intervention if adequate progress is not made.
