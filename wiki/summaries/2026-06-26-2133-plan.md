# Plan: Update "Status Exam" to "Neurobehavioral Exam (STT)" in Documentation

## Overview
This plan outlines the steps required to update all documentation files to reflect the rebranding of the "Status Exam" feature to "Neurobehavioral Exam (STT)", aligning documentation with changes already implemented in the codebase.

## Goals
- Ensure consistent terminology across all docs and notes.
- Replace legacy terms ("Status Exam", "Neurobehavioral Status Exam", "Neurobehavioral Exam") with the canonical name **Neurobehavioral Exam (STT)**.
- Preserve contextual distinctions (e.g., "Neurobehavioral Exam (STT) transcript" where the content type must be explicit).

## Tasks

### 1. Identify Documentation Files
- Scan `docs/` and `notes/` directories for any remaining references to the old terminology.
- Targets include both direct feature name mentions and compound phrases.

### 2. Update Documentation Content
- Replace "Status Exam" → "Neurobehavioral Exam (STT)"
- Replace "Neurobehavioral Status Exam" or "Neurobehavioral Exam" → "Neurobehavioral Exam (STT)"
- Maintain context-appropriate phrasing (e.g., transcript references).
