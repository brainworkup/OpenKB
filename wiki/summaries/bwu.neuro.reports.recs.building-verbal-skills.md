# Building Verbal Skills — Recommendations for KB

**Source:** bwu.neuro.reports.recs.building-verbal-skills
**Tags:** verbal, speech, language, recommendations

## Overview
This document provides evidence-informed recommendations for parents and teachers to support KB's verbal expression, language development, vocabulary, and comprehension skills across home and classroom settings.

## Key Recommendation Areas

### Verbal Expression & Conversation
- Set aside dedicated evening time for family discussion of the day's events, minimizing distractions.
- Adults should ask **open-ended questions** and avoid interrupting KB; follow-up with elaborating questions.
- Provide **positive feedback** (reciprocal conversation, encouraging elaboration, affirming contributions) to reduce reluctance to express.

### Shared Reading & Early Literacy
- Use **dialogic reading**, an evidence-based shared reading strategy, to build early literacy, [[concepts/vocabulary-development]], and comprehension.
- Ask child-specific questions during reading to encourage interest, comprehension, and enjoyment.
- See [[concepts/dialogic-reading]]

### Analogical Reasoning
- Practice analogical reasoning through sentence-completion games (e.g., "Pears are bigger than cherries and cherries are bigger than..."; "Humans are to homes as birds are to...").
- This targets higher-order verbal reasoning closely linked to [[concepts/cognitive-domains]].

### Verbal Categorization & Vocabulary
- Play **naming games**: list objects by a shared characteristic (color, texture, shape).
- Use everyday activities (sorting laundry, putting away toys) to practice object classification.
- Expose KB to new vocabulary in real-world contexts (e.g., naming objects in a store).
- Reinforce new vocabulary through multimodal practice: finger-painting letters, clay molding, flash cards, sentence creation.
- See [[concepts/vocabulary-development]]

### Object Attributes
- Adults describe an object's attributes; KB identifies the object — builds descriptive language and listening skills.

### Story-Time Activities
- Read stories multiple times with deliberate changes to characters, action, or sequence; KB identifies and describes what changed.
- Ask KB to complete incomplete stories or participate in story dramatization.

### Classroom Comprehension Strategies
- **Pre-teaching:** Introduce upcoming content and key vocabulary before lessons.
- **During lessons:** Use visual supports (pictures, diagrams, graphs); provide verbal cues for important information; supply written outlines of main ideas.
- **After lessons:** KB paraphrases key information immediately to consolidate learning.
- Reduce complexity of classroom discourse: control vocabulary level, sentence length, grammatical complexity, and number of steps in commands; provide written support.
- Use **visual categorization** to organize new information meaningfully.
- Use **visual cues** to teach sequencing operations and facts.
- These strategies align with broader [[concepts/iep-accommodations]] and [[concepts/attention-intervention-strategies]] frameworks.
