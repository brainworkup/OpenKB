# WAIS-IV (Wechsler Adult Intelligence Scale, Fourth Edition)

The **Wechsler Adult Intelligence Scale, Fourth Edition (WAIS-IV)** is one of the most widely used standardized instruments in [[concepts/neuropsychological-assessment-automation]] and clinical psychology. It is designed to assess cognitive ability across multiple domains in individuals aged 16 to 90 years.

## Structure

The WAIS-IV is organized into four primary composite indexes, each composed of multiple subtests:

| Index | Abbreviation | Core Subtests (examples) |
|-------|-------------|-------------------------|
| Verbal Comprehension Index | VCI | Similarities, Vocabulary, Information |
| Perceptual Reasoning Index | PRI | Block Design, Matrix Reasoning |
| Working Memory Index | WMI | Digit Span, Arithmetic |
| Processing Speed Index | PSI | Symbol Search, Coding |

A Full Scale IQ (FSIQ) is derived from all four indexes.

## Scoring

The WAIS-IV uses a multi-level scoring system:

- **Raw Scores** — total correct responses on a given subtest
- **Scaled Scores** — subtest-level normative scores (mean = 10, SD = 3)
- **Composite Index Scores** — standard scores (mean = 100, SD = 15)
- **Percentile Ranks** — normative standing relative to age-matched peers

Classifications range from Extremely Low through Superior, anchored to the standard score distribution.

## Digit Span Subtest

The **Digit Span** subtest is a key component of the [[concepts/working-memory-index]]. It requires examinees to repeat sequences of digits in the same order (Digits Forward), in reverse order (Digits Backward), and in ascending numerical order (Digit Sequencing). It is a primary measure of [[concepts/working-memory]] capacity and auditory attention.

In the evaluation documented in [[summaries/NP-20240415-001_report]]:
- Raw Score: 16
- Scaled Score: 9
- Percentile Rank: 37th
- Classification: Average

## Relevance to Cognitive Domains

The WAIS-IV spans several [[concepts/cognitive-domains]]:

- **Working Memory** — via WMI (Digit Span, Arithmetic)
- **Processing Speed** — via PSI
- **Verbal Reasoning** — via VCI
- **Visuospatial/Perceptual Reasoning** — via PRI

Because of this multi-domain coverage, it is frequently used as an anchor instrument in comprehensive neuropsychological batteries.

## Use in Neuropsychological Reports

In [[concepts/neuropsychological-reporting]], WAIS-IV scores are routinely included in [[concepts/clinical-report-structure]] to establish baseline intellectual functioning, identify domain-specific weaknesses, and support diagnostic formulations such as [[concepts/mild-cognitive-impairment]] or neurodevelopmental conditions.

The WAIS-IV is commonly paired with memory batteries, executive function measures, and behavioral rating instruments to form a complete cognitive profile. Score interpretation guidelines, including discrepancy analysis, are central to [[concepts/neuropsychological-score-interpretation]].

## Limitations

- A single subtest (e.g., Digit Span alone) is insufficient for drawing broad conclusions about cognitive functioning.
- Scores must be interpreted in the context of demographic norms, effort validity, and the full test battery.
- As noted in [[summaries/NP-20240415-001_report]], administering only one WAIS-IV subtest severely limits interpretive scope.
