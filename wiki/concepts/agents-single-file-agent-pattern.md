# Single File Agent Pattern

The Single File Agent Pattern is a software design pattern where all logic and functionality of an agent are contained within a single Python file. This approach aims to simplify the development process, reduce dependencies, and increase maintainability.

## Key Benefits

*   Simplified development with reduced complexity
*   Reduced dependencies on external modules or libraries
*   Increased maintainability due to reduced codebase size

## Relation to AGENTS Document

The Single File Agent Pattern is closely related to the AGENTS document, which describes a local neuropsychological report soul agent powered by a local LLM + lightweight RAG. The pipeline in the AGENTS document uses this pattern to implement its three stages: building an index from PDF/TXT/MD reports, training a soul profile from indexed chunks, and drafting a new report section.
