# Working Memory Index (WMI)

The **Working Memory Index (WMI)** is one of the four primary composite index scores derived from the [[concepts/wais-iv]] (Wechsler Adult Intelligence Scale, Fourth Edition). It quantifies an individual's capacity to hold information in short-term memory, attend to that information, and mentally manipulate it to produce a result or output.

## Constituent Subtests

The WMI is composed primarily of two core subtests:

- **Digit Span** — requires the examinee to repeat sequences of numbers forwards, backwards, and in sequence order; taps auditory attention and short-term memory manipulation.
- **Arithmetic** — measures mental arithmetic under time pressure; taps numerical reasoning and working memory capacity.

A supplemental subtest, **Letter-Number Sequencing**, may also contribute depending on the administration version.

## Score Interpretation

WMI scores follow the standard WAIS-IV composite metric:

| Standard Score Range | Classification |
|----------------------|----------------|
| ≥ 130 | Extremely High |
| 120–129 | Very High |
| 110–119 | High Average |
| 90–109 | Average |
| 80–89 | Low Average |
| 70–79 | Borderline |
| ≤ 69 | Extremely Low |

Individual subtest scaled scores (mean = 10, SD = 3) and their associated percentile ranks are used to interpret performance within the WMI domain before computing the composite.

## Clinical Relevance

Working memory is a foundational cognitive resource that supports a wide range of higher-order functions. Deficits in WMI performance are commonly observed in:

- [[concepts/mild-cognitive-impairment]] (MCI), particularly the amnestic subtype
- [[concepts/executive-function-deficits]]
- Attention-deficit conditions
- Neurodevelopmental disorders including [[concepts/autism-spectrum-disorder-clinical-features]]

Because [[concepts/working-memory]] underpins attention regulation, processing speed, and [[concepts/cognitive-domains]] broadly, a depressed WMI score often has cross-domain implications even when other indices appear intact.

## In NP-20240415-001

In the case documented in [[summaries/NP-20240415-001_report]], the **Digit Span** subtest was the sole test administered. The patient achieved:

- **Raw Score:** 16
- **Scaled Score:** 9
- **Percentile Rank:** 37th
- **Classification:** Average (per standard norms)

The report clinically characterized this as below-average performance and linked the result to the WMI, framing it as consistent with a working diagnosis of amnestic MCI. It is important to note that a single subtest cannot yield a valid WMI composite — the index requires at least two subtests. The report's use of "Working Memory Index" in this context reflects an interpretive extrapolation rather than a formally calculated composite score.
